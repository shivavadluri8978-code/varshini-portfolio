# Varshini Lakkakula — Premium Portfolio
A premium, editorial-style responsive portfolio built from the supplied resume.

## Run
Open `index.html` directly or use VS Code Live Server.

## GitHub Pages
Create a repository, upload all files, then use **Settings → Pages → Deploy from branch → main → root**.

## Replace before publishing
- GitHub URL
- LinkedIn URL
- `resume.pdf` if a newer resume is available

## Certificate gallery
The `assets/certificates/` folder contains three uploaded certificates displayed in the Certificate Wall section.
